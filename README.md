# AI Agent Tool Library

**AI agent metadata standardization, routing evaluation, and reliability engineering.**  
A selected portfolio overview of my internship work at Wizpresso.

## Project Overview

I worked on an AI Agent Tool Library where inconsistent tool definitions and ambiguous descriptions made reliable routing difficult. My focus was to standardize metadata, strengthen validation, design repeatable benchmarks, and evaluate improvements systematically.

## What I Worked On

- **Metadata design:** Built reusable `ToolDefinition` and `AgentDefinition` models using Python and **Pydantic**.
- **Quality & validation:** Developed structured checks to identify missing fields, inconsistent parameters, and ambiguous usage boundaries.
- **Evaluation:** Created a benchmark of **60 routing scenarios** and automated testing with **pytest**.
- **Reliability improvements:** Analyzed failure cases, improved tool descriptions and disambiguation rules, and compared results using **precision, recall, and F1**.
- **Knowledge transfer:** Prepared technical documentation and a **19-slide final presentation**, explaining system workflows, evaluation methodology, results, and limitations.

## Key Result

**Tool-selection F1: 0.645 → 0.763 (+18.3% relative improvement)** in the defined project evaluation.

> This metric describes the project benchmark, not a guaranteed production accuracy rate.
